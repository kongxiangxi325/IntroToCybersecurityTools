## 一、作业背景

后面几周的课程要在自己的 Windows 电脑上反复使用一批工具软件，同时也要用到查找官网、压缩解压、收发邮件等基本操作。本实验先把这些"装备"配齐、把基本功练熟。

本次推荐软件均为常见免费软件，请只从**第七节给出的官方下载地址**或 **Microsoft Store** 安装，不要使用百度搜索结果里的"高速下载器"或第三方下载站安装包。

### 1.1 Windows 的基本正确风格

一台 Windows 电脑用得对不对，先看三条基本风格：

1. **任何时候无广告弹窗**：右下角不弹"热点资讯""xx 提醒您"，软件用完不会冒出一堆全家桶。第三方杀毒、下载站的"高速下载器"和捆绑安装是弹窗广告的三大来源；
2. **浏览器主页没有广告**：打开浏览器就是干净的搜索页（本作业统一用 Bing），主页和搜索引擎不被导航站劫持，新建标签页没有资讯流和推广；
3. **桌面干净清爽**：桌面只保留少量常用图标，安装包、压缩包用完即删或归档进文件夹，不把桌面当仓库。

本次作业和这三条一一对应：第二、三节装正规工具、卸第三方杀毒，加上 4.7 的开机启动项清理，对应第 1 条；4.6 的主页与搜索引擎设置对应第 2 条；建议顺手把桌面整理一遍，体会第 3 条。以后每装一个软件，都可以用这三条检查一遍。

## 二、安装推荐软件（至少 5 款）

下面 10 款都是 Windows 上口碑很好的免费软件，**至少安装 5 款并各简单用一次**，其中 **Everything、Geek Uninstaller、WizTree 三款为必装**（见 2.3），其余七款至少再装 2 款，鼓励全部安装。

**下载提示（中国大陆网络环境）**：优先打开 **Microsoft Store** 搜索安装（QuickLook、Microsoft PowerToys、Snipaste、LocalSend 等商店里都有）；商店没有的再按第七节官网地址下载。部分官网服务器在境外，国内访问可能较慢，多试几次或换个时段即可；除三款必装软件外，个别官网完全打不开时，先跳过它，用其他软件凑满 5 款即可；三款必装软件请多试几次或换个时段下载，**不要**改用搜索结果里的第三方下载站。

### 2.1 这十款软件分别是干什么的

- **Everything（文件搜索）**：按文件名瞬间搜遍全盘的搜索工具。Windows 自带搜索慢得让人不想用，Everything 打开后输入文件名，结果毫秒级出现；装完它，"文件放哪儿了"这个问题就消失了。
- **Geek Uninstaller（干净卸载）**：轻量级卸载工具。卸载软件后会自动扫描并清理残留的文件和注册表项，避免"卸了还有尾巴"；本实验第三节卸第三方杀毒、4.7 清理启动项时都会用到它。
- **WizTree（磁盘空间分析）**：几秒钟扫完整个磁盘，用方块图列出哪个文件夹、哪个文件最占空间。C 盘又红了不知道删什么？用它一看便知。
- **油猴 Tampermonkey（浏览器脚本管理器）**：给浏览器装"用户脚本"的管理器。脚本可以让网页变得更顺手，比如视频网站增强、页面去广告、自动展开全文等；脚本从 Greasy Fork 等网站一键安装，4.5 节会实际操作。
- **LocalSend（局域网传文件）**：开源免费的跨设备传文件工具，手机和电脑连同一个 Wi-Fi 就能互传照片、文件，不用数据线、不用登录任何账号，体验类似 iPhone 的 AirDrop。
- **7-Zip（压缩解压）**：老牌开源压缩软件，支持 zip、7z 等常见格式，7z 格式压缩率特别高，完全免费无广告。装好后右键菜单就能压缩和解压，4.2 节会用它。
- **Snipaste（截图贴图）**：截图之外还能把截图"钉"在桌面上。F1 截图、F3 贴图，贴在屏幕上的图可以半透明、可以缩放，对着图片抄写内容、比对着填表格时特别好用。
- **QuickLook（快速预览）**：在资源管理器里选中文件按一下空格，立刻弹出预览窗口——图片、PDF、视频、压缩包都能看，再按空格关闭，不用真的把文件打开。Mac 用户的经典体验，Windows 靠它补齐。
- **Microsoft PowerToys（微软官方效率工具集）**：微软自己出的 Windows 增强包，包含一堆实用小工具：窗口分区管理 FancyZones、批量重命名 PowerRename、屏幕取色器、窗口置顶等，每个都值得打开试一次。
- **PotPlayer（视频播放器）**：格式支持极全的视频播放器，各种"下下来放不出来"的视频它都能放，倍速播放、加载字幕、逐帧看都方便，界面还能高度自定义。

## 三、卸载第三方杀毒软件（建议）

很多新电脑预装了金山毒霸、360、麦咖啡（McAfee）、火绒等第三方杀毒软件，它们常驻后台、拖慢开机，还爱弹广告和捆绑全家桶。**Windows 自带的 Microsoft Defender 已经足够好用**，建议把第三方杀毒全部卸载，只保留 Windows Defender。

操作建议：

1. 打开 **设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护**，确认防病毒软件是"Microsoft Defender 防病毒"；
2. 在 **设置 → 应用 → 已安装的应用** 里找到第三方杀毒软件（或安全管家类全家桶），用 Geek Uninstaller 或系统自带的卸载功能卸载；
3. 卸载后重启电脑一次。

> 本节为**建议内容**，不强制卸载（例如实验室公用电脑、家长单位统一安装的电脑可以保留）；不卸载不影响作业通过。但下表必须填写，没有装过任何第三方杀毒软件就填"无"。

### 4.6 设置浏览器主页与默认搜索引擎

Edge 和 Chrome 新装好或被"全家桶"动过之后，主页常被改成推广导航站、搜索默认成不明引擎，还塞满资讯弹窗和广告。请把两个浏览器都设置成干净的状态。

**Microsoft Edge**：

1. 打开 **设置 → 开始、主页和新建标签页**，把"启动时"设为**打开以下页面**，添加 `https://www.bing.com`；
2. 同一页面中，把"主页"按钮（如已开启）设为 `https://www.bing.com`；
3. 打开 **设置 → 隐私、搜索和服务**，在"地址栏和搜索"里把搜索引擎改为 **Bing**；
4. 在 **设置 → 开始、主页和新建标签页** 里关闭新建标签页的推广内容：将页面布局调成"自定义"或"安静"，关闭"资讯快讯""每日精选壁纸""快捷方式"等推广开关；
5. 在 **设置 → 隐私、搜索和服务** 底部关闭个性化广告与"购物节省"等推送类功能。

**Google Chrome**：

1. 打开 **设置 → 启动时**，选择**打开特定网页或一组网页**，添加 `https://www.bing.com`；
2. 打开 **设置 → 外观**，开启"显示'主页'按钮"并设为 `https://www.bing.com`；
3. 打开 **设置 → 搜索引擎**，把地址栏中使用的搜索引擎改为 **Bing**；
4. Chrome 新标签页本身没有资讯推广，如安装过会改主页的国产软件，请用第三节的 Geek Uninstaller 卸载并重置浏览器设置。

### 4.7 管理开机启动项

很多软件安装后会把自己加进开机自启，电脑越用开机越慢、右下角图标越堆越多——这也是"全家桶"拖慢电脑的主要手段之一。

1. 按 4.1 里学到的 `Ctrl + Shift + Esc` 打开任务管理器，切换到 **启动应用** 标签（Windows 10 叫"启动"）；
2. 逐条查看列表里的启动项，把"已启用"且明显不需要开机自启的项目（各种"助手""管家""自动更新程序"等）右键选择 **禁用**；拿不准的先保留，不必全禁；
3. 系统和驱动类项目（Windows 安全中心、显卡/触摸板驱动等）**不要禁用**；
4. 也可以在 **设置 → 应用 → 已安装的应用** 里管理同一批启动项（Windows 11 每个应用有"启动"开关）。

## 六、拿下教育账号：JetBrains 学生授权与 GitHub 学生包

学校给每个人都配了 edu 教育邮箱，它能兑换两大"学生福利"——平时要按年花钱订阅的开发工具和服务，在读期间免费。现在不写代码也先把账号拿下来，以后用的时候直接登录就行。

### 6.1 JetBrains 学生授权

JetBrains 是最主流的开发工具厂商，IntelliJ IDEA、PyCharm、CLion、WebStorm 等 IDE 的专业版平时按年收费，学生授权在读期间免费（每年可续）。申请步骤：

1. 用 edu 邮箱注册 JetBrains 账号：<https://account.jetbrains.com/>；
2. 打开学生计划页面 <https://www.jetbrains.com/community/education/#students>，选择 **Apply**（Students and teachers 下的学生申请）；
3. 申请方式选 **University email address**（用学校邮箱验证），填入自己的 edu 邮箱；
4. 提交后 edu 邮箱会收到确认邮件，按邮件提示完成验证，授权一般几分钟到一天内生效；
5. 生效后用该账号登录 JetBrains Toolbox 或任意一款 IDE，即可免费激活全家桶。

### 6.2 GitHub 学生开发包（Student Developer Pack）

GitHub Student Developer Pack 是 GitHub 面向学生的福利包，包含 GitHub Pro、GitHub Copilot 学生免费、多家云服务和开发工具的免费额度，还能反过来用来授权 JetBrains。申请步骤：

1. 先注册/登录 GitHub 账号，在 **Settings → Emails** 里添加自己的 edu 邮箱并完成验证邮件；
2. 打开 <https://education.github.com/>，进入学生包申请页（Get student benefits）；
3. 按提示填写学校名称、在读证明等信息；如果要求上传学生证或在读证明照片，按要求提供即可；
4. 提交后等待审核，通常几小时到几天，通过后账号页面会显示 Pro 标识，Pack 权益自动生效。

> **提示**：GitHub 在中国大陆访问时快时慢，可以借助开源工具 **Watt Toolkit**（原名 Steam++，官网 <https://www.watttoolkit.com/>，Microsoft Store 里也有）加速：安装后在「网络加速」里勾选 GitHub 并启动加速，再刷新申请页面即可；不想装工具就换个时段再试。两边的审核都可能要等几天，**现在就把两个申请都提交**，状态填"审核中"也算完成本次作业。


完成后填写下表：

| 项目             | 申请状态 | 一句话说明（审核中、遇到的问题等）                        |
| -------------- | ---- | ---------------------------------------- |
| JetBrains 学生授权 | 审核中  | 已用 edu 邮箱提交申请，等待确认邮件完成验证                 |
| GitHub 学生开发包   | 审核中  | 已在 education.github.com 提交申请并填写在读信息，等待审核 |

本节不要求截图，也不要求审核已经通过——**用 edu 邮箱把两个申请都提交，并如实填写状态，即算完成**。两个账号请保管好账号和密码，后面的课程会用到。
